# Flux 1.5 — 2026-06-02

A focused maintenance release with a single Dashboard fix.

## Fixes

### Dashboard live trio no longer wraps large grid values

The live Solar / House / Grid trio on the Dashboard rendered its value at a fixed size. When any of the three crossed 10 kW — five characters plus a unit, e.g. "11.51 kW" — the value overflowed its column and the trailing digit wrapped onto a second line.

Values that run past four characters now drop to a slightly smaller font and are pinned to a single line, so the reading and its unit always stay together. Values under 10 kW are unchanged, and the rule applies to all three columns, so House or Solar crossing 10 kW gets the same treatment.

## Upgrade Notes

No breaking changes. This is an iOS/macOS app-only release — no backend, API, or data changes.
